Implementation timeline — typically ~4 weeks to first deployment

We get the leadership cohort live in about 4 weeks, run a structured test period, then open Skills up to the rest of the company. After launch we do QBRs every 3 months to expand the Skills library based on real usage.

1Discovery
  • 2-hour workshop with the leadership team
  • Interviews with use-case owners
  • Document collection list finalized
  • Initial Skills and test cohort defined
2Skills Development
  • EPCH builds Skills locally in your Claude Code
  • All data stays inside your environment
  • Each Skill bundled with knowledge, prompts, brand assets
  • Review of voice, principles and quality bar with leadership
3Soft Launch
  • Skills deployed into Claude Chat for the test cohort
  • Weekly checkins and rapid Skill iteration
  • Output-quality review against real work
  • Workshop post-trial — wins, gaps, next priorities
4Company Launch
  • Skills deployed to all employees' Claude Chat
  • EPCH-led training sessions (as desired)
  • Documentation and video walkthroughs for each Skill
  • Quarterly check-ins to expand the Skills library
